# Curio Life

Curio Life — экосистема приложений для повседневных ситуаций. Её первое приложение, **Curio Now**, сохраняет временно важную информацию в момент, когда она нужна, и автоматически удаляет её после завершения срока жизни.

## Curio Now

Пользователь фотографирует номер, табличку, билет, код, расписание или другой объект. Приложение сразу создаёт локальную карточку, распознаёт полезные детали и добавляет контекст съёмки.

Примеры:

- место и стоимость парковки;
- код двери или Wi-Fi;
- номер электронной очереди;
- билет или талон;
- расписание на табличке;
- номер камеры хранения;
- временная инструкция, адрес или место встречи.

## Основные принципы

- данные хранятся локально на устройстве;
- аккаунт и облачная синхронизация не требуются;
- в приложении нет рекламы;
- карточка сохраняется до начала распознавания, поэтому исходная фотография не теряется;
- каждая карточка имеет срок жизни и исчезает автоматически;
- GPT не требуется для первой версии, но архитектура допускает его подключение в будущем.

## Возможности первой версии

- создание карточки непосредственно через камеру;
- импорт изображения из медиатеки;
- распознавание русского и английского текста на устройстве;
- извлечение номеров, кодов, времени и стоимости;
- сохранение координат места съёмки;
- автоматический срок жизни карточки;
- продление срока и немедленное удаление;
- локальное восстановление недавно исчезнувших карточек;
- отметка данных с низкой уверенностью распознавания.

## Технологии

- Swift и SwiftUI
- SwiftData
- MVVM, Repository и protocol-oriented services
- Apple Vision OCR
- Core Location
- PhotosUI и UIKit camera capture
- async/await

## Архитектура

Интерфейс не зависит от конкретного механизма анализа. Локальный Vision-анализатор реализует общий протокол `CardAnalyzer`. В будущем к конвейеру можно добавить GPT-анализатор и внешние источники данных без переписывания экранов, ViewModel и локального хранилища.

Карточка использует универсальную модель фактов вместо отдельных типов для парковки, билетов или кодов. Каждый факт хранит значение, тип, уверенность распознавания и источник данных.

## Приватность

Первая версия работает без собственного сервера и не отправляет фотографии на внешнюю обработку. Публичный раздел портфолио содержит описание проекта; исходный код приложения хранится отдельно.
