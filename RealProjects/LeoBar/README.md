# Leo Bar Bistro

Самостоятельное iOS-приложение для ресторана Leo Bar Bistro. Проект объединяет клиентский интерфейс, локальное хранение и отдельный тестовый серверный контур.

## Задача

Сделать взаимодействие гостя с рестораном быстрым и понятным: показать меню, принять заказ на самовывоз, отправить заявку на бронирование и сообщать об изменении статуса.

## Возможности

- актуальное меню с категориями и карточками блюд;
- подробная информация о блюде и примерная калорийность;
- корзина и оформление заказа на самовывоз;
- бронирование по дате, времени и количеству гостей;
- разделы «Мои заказы» и «Мои брони»;
- обновление статусов заказа и бронирования;
- звонок в ресторан и открытие адреса на карте;
- две темы главного экрана;
- русский, английский и испанский языки;
- фирменная анимация логотипа и haptic feedback;
- веб-панель ресторана для обработки заявок.

## Технологии

- Swift и SwiftUI
- SwiftData
- MVVM
- async/await и REST API
- Yandex Cloud Functions и YDB
- локализация и Accessibility
- Liquid Glass и системные анимации iOS

## Архитектура

Интерфейс, модели, состояние экранов, сетевой слой, данные и ресурсы разделены по назначению. Клиент не подключается напрямую к ресторанной системе: запросы проходят через отдельный серверный слой.

## Защита проекта

Исходный код, серверная конфигурация и ключи доступа не публикуются. Этот раздел предназначен только для демонстрации выполненной работы и технических навыков.
